# Architecture Decision Records

Store significant architecture decisions in this directory. Use sequential identifiers and descriptive filenames, for example `0001-use-postgresql.md`.

## Index

| ADR | Title | Status | Date |
|---|---|---|---|
| | | | |

## Create a decision record

1. Copy `template.md` to the next available number and a short kebab-case title.
2. Set status to Proposed.
3. Record context, decision drivers, realistic alternatives, and consequences.
4. Request review from the affected owners.
5. Update the status and index after the decision is made.

## Status values

- Proposed
- Accepted
- Rejected
- Deprecated
- Superseded

Do not rewrite history when a decision changes. Create a new ADR that supersedes the old one and link both records.
