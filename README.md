## Installation

Copy the skill into your agent skills directory:

```bash

cp SKILL.md .claude/skills/architecture-decision-records/SKILL.md
```

Ask your AI coding assistant to use **Architecture Decision Records** when handling a related task. It should follow the instructions in `SKILL.md`.
